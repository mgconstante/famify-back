Famify

Nossa aplicação busca conectar jogadores, facilitando o encontro de jogadores para formarem uma família Steam.
A aplicação importa a biblioteca do usuario por meio do Steam Id, e na aplicação o usuário define sua lista de desejos. O sistema utiliza disso para fazer o match dos usuários

Tecnologias Utilizadas:
Java
SpringBoot
MySql
Postman
